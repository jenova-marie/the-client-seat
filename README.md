# Getting Started Making Claude Do Everything

A series for people who have never opened a terminal and are about to join a
real software project anyway. The tools are the example. Learning with AI as
your tutor, and catching it when it's wrong, is the subject.

## Reading order

1. [Part 0: Why I'm making my client learn with AI](00-why-learn-with-ai.md) (free) — the series contract: paste-this prompts and the verification habit
2. [Part 1: Your first tutor session](01-your-first-tutor-session.md) (free) — how to ask AI to teach you and quiz you back; milestone: free claude.ai account
3. [Part 2: Catching Claude being wrong](02-catching-claude-being-wrong.md) (free) — hallucinations, the six tells, and the verification card
4. [Part 3: Don't fear the clear](03-dont-fear-the-clear.md) (free) — context, clear vs compact, the CONTINUATION.md ritual; milestone: first Project
5. [Part 4: What a repo actually is](04-what-a-repo-actually-is.md) (free) — repo, commit, history, branch, main, and why not a shared folder; milestone: GitHub account
6. [Part 5: Joining the project](05-joining-the-project.md) (paid plan) — collaborators, the Claude GitHub App, Plan mode as the viewer posture; milestone: repo open at claude.ai/code
7. [Part 6: Your first contribution](06-your-first-contribution.md) (paid plan) — branches, diffs, pull requests; milestone: vision doc, first PR
8. [Part 7: Bringing your data along](07-bringing-your-data-along.md) (paid plan) — data shapes, exports, bad data, never real user data in a repo; milestone: scrubbed sample, second PR
9. [Part 8: Reading code without being a coder](08-reading-code-without-being-a-coder.md) (paid plan) — asking the codebase questions, sessions as study notes
10. [Part 9: Teach Claude a skill](09-teach-claude-a-skill.md) (paid plan) — a skill is a saved prompt in the repo; milestone: the continuation skill, third PR
11. [Part 10: Working from anywhere](10-working-from-anywhere.md) (paid plan, optional) — Desktop app Code tab, Local vs Cloud, the phone app
12. [Part 11: How we work together now](11-how-we-work-together-now.md) (paid plan) — the PR review loop between developer and client

## How to use the prompts

Every part has boxes marked "paste this into Claude." The exact text of each
lives in [`prompts/`](prompts/). Copy the whole box.
